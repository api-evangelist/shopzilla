# Shopzilla

> Shopzilla is a comparison-shopping website that lets consumers search across
> thousands of merchants to compare products, prices and merchant ratings. It is a
> consumer brand operated by Connexity, a Taboola company, alongside sibling
> properties Bizrate, Beso and PriceGrabber. Shopzilla itself publishes no public
> API, no developer portal and no machine-readable contract.

Provenance: GENERATED by the API Evangelist enrichment pipeline on 2026-08-13 from
this repository's apis.yml and probe artifacts. Shopzilla does not publish an
llms.txt of its own — https://www.shopzilla.com/llms.txt returns HTTP 403 from an
AWS WAF bot challenge, and no Shopzilla-branded developer host resolves in DNS.

## What an agent can and cannot do here

- There is **no callable Shopzilla API**. No OpenAPI, AsyncAPI, GraphQL SDL, MCP
  server, agent card, SDK or webhook surface was found on any host after a full
  contract-discovery pass.
- `developer.shopzilla.com`, `api.shopzilla.com` and `docs.shopzilla.com` do not
  resolve (NXDOMAIN).
- `www.shopzilla.com` is behind AWS CloudFront + AWS WAF. The root returns HTTP 202
  with `x-amzn-waf-action: challenge`; every other path returns HTTP 403. Automated
  clients are challenged by design. Do not attempt to evade it.

## The developer program belongs to the operator, not to this brand

The affiliate/publisher API program historically marketed as the "Shopzilla Publisher
Program" is today published by **Connexity** under its own brand, on its own hosts.
It is recorded here as context only and is deliberately NOT catalogued as a Shopzilla
contract, because every artifact identifies itself as Connexity:

- Connexity Publisher Resource Center: https://pubresources.connexity.com/hc/en-us
- Connexity Monetization API doc page (title: "Connexity Monetization API",
  contact: info@connexity.com): https://api.cnnx.link/
- Publisher reporting host: https://publisher-api.connexity.com
- Legacy Catalog API host (still answering, no spec published):
  https://catalog.bizrate.com/services/catalog/v1/

An agent looking for these APIs should look under Connexity, not Shopzilla.
